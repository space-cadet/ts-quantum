# Project Brief: ts-quantum
*Last Updated: 2026-01-04 11:11:11 IST*

## Overview
ts-quantum is a comprehensive TypeScript library for quantum mechanics calculations and utilities, successfully published as an independent npm package with extended development including interactive web demonstrations and performance optimizations.

## Purpose
Provide a complete quantum mechanics library in TypeScript that enables:
- Quantum state vector operations with arbitrary dimensional support
- Standard quantum gates, operators, and measurements
- Density matrix operations for mixed states
- Angular momentum algebra and Wigner symbols
- Quantum information measures and metrics
- Geometric quantum mechanics calculations
- High-performance sparse operator support for large systems
- Interactive web-based educational demonstrations

## Scope
- **Core functionality**: Quantum states, operators, gates, measurements
- **Advanced features**: Angular momentum, Wigner symbols, sparse matrices, geometric metrics
- **Educational**: Interactive web demonstrations, visualization tools
- **Performance**: Sparse operator support, O(N) scaling for large systems
- **Target users**: Researchers, students, developers, quantum computing practitioners
- **Platforms**: Node.js >= 14.0.0, Modern web browsers

## Key Requirements
- Zero external workspace dependencies (mathjs only)
- Clean, well-documented public API
- Comprehensive test coverage (94%+ pass rate)
- Published and maintained on npm registry
- Professional documentation with examples
- Web-accessible interactive demonstrations
- Performance optimization for high-dimensional systems
