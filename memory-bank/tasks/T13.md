### 3. Critical Bug Fix: partialTrace
- **File**: `src/operators/operator.ts`
- **Bug**: `traceRange` used `this.dimension` (full Hilbert space) instead of `traceOutDim` (subsystem dimension)
- **Impact**: Reduced density matrices had trace=2 instead of 1, causing negative entropy and Schmidt coefficients > 1
- **Fix**: Changed to `Array(traceOutDim).fill(0).map((_, i) => i)`
- **Verification**: All 451 tests pass; Bell state entropy = ln(2) ✅
