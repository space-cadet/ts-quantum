## Context

### Architecture Overview
The QRW demo page extends the existing T9 implementation by creating a dedicated, full-featured interface for exploring quantum random walks across multiple dimensions, coin operators, and boundary conditions.

### Key Features to Implement
1. **1D Walks**:
   - Hadamard coin (from T9)
   - Grover coin (alternative operator)
   - Periodic boundary conditions (wrap-around)
   - Reflecting boundary conditions (coin flip at edges)

2. **2D Walks**:
   - 4-direction coin (UP, DOWN, LEFT, RIGHT)
   - Rectangular lattices
   - Periodic toroidal lattices
   - Reflecting boundary conditions

3. **Analysis & Comparison**:
   - Variance growth: quantum vs classical overlay
   - Position probability distributions (snapshots at different times)
   - Classical random walk reference
   - Statistical measures (center of mass, spreading rate)

4. **Physical Insights**:
   - Quantum advantage visualization (quadratic vs linear spreading)
   - Classical limit behavior
   - Diffusion equation emergence
   - Telegraph equation investigation

### Design Constraints
- Leverage existing library infrastructure (StateVector, MatrixOperator, SparseOperator)
- Maintain performance for lattices up to 31×31 (2D)
- Use sparse operators for shift operations
- Implement in TypeScript with proper types
- Create reusable functions for all variants

## Known Limitations
- 2D walks may require sparse operators for lattices >15×15
- SVG visualization performance depends on browser
- Animation speed fixed at 500ms per step (from T9)
