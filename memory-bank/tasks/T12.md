### 4. Bloch Sphere Geometry (`src/geometry/quantumDistance.ts`)

- **Tests:** Fixed complex Hermitian test (added `computeEigenvectors: true`); fixed Pauli Z test correspondence

### 7. Integration Tests (`__tests__/integration.test.ts`)
