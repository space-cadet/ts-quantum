## Context
The quantum random walk is a fundamental quantum algorithm demonstrating:
- Quantum superposition at each lattice position
- Coin state flips via Hadamard operator
- Conditional position shifts (LEFT/RIGHT)
- Boundary reflection for unitarity preservation
- Quadratic spreading (variance ∝ t²) vs classical linear spreading

### Implementation Details
- **Coin Space**: 2D (LEFT, RIGHT coin states)
- **Position Space**: 1D lattice with N positions (5-31)
- **Total Dimension**: 2N (composite Hilbert space)
- **Shift Operator**: Sparse matrix (~4N non-zero entries)
- **Memory**: Highly efficient with sparse operators
- **Animation**: 500ms per step for comfortable viewing

### Key Technical Decisions
1. **Sparse Operators**: Used for shift operator to avoid dense matrix explosion
2. **Boundary Reflection**: Coin flip at boundaries preserves unitarity
3. **Tensor Product**: Coin ⊗ Identity for proper composite space evolution
4. **Stateful Step Function**: Maintains state between calls for interactive use
5. **SVG Visualization**: Real-time graph updates with probability bars
6. **Animation Control**: Global variables prevent concurrent animations

- Web bundle: 3.1 MB (includes all dependencies)
- Animation overhead: Minimal (SVG update only)

## Design Decisions Log
- **Why 500ms per animation step?** Comfortable viewing speed; allows observation of spreading
- **Why sparse shift operator?** Avoid O(N²) memory for dense operator
- **Why boundary reflection?** Preserves unitarity without amplitude accumulation
- **Why max 100 steps?** Practical limit for browser animation; covers realistic quantum dynamics
- **Why disable controls during animation?** Prevent parameter changes mid-evolution

## Known Limitations
- Dense coin operator (2×2) acceptable due to small size
- SVG rendering may slow for very large lattices (>31 positions)
- Animation frame rate depends on browser/system performance
- No support for other coin operators yet (future enhancement)
